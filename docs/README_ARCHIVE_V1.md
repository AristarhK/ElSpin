# Электроспиннинг: Fortran 3D + поле шприцевой иглы

Проект расширяет приложенную стационарную модель трёхмерной нестационарной
вязкоупругой струёй, осаждением на коллектор, интерактивными графиками,
терминальным вводом и параметрическими исследованиями. Расчётное ядро —
**Fortran 2008**; **NumPy/SciPy** решают поле иглы и обрабатывают данные,
**Plotly/Matplotlib** строят графики. Исходный проект сохранён в `original/`.

**Это исследовательская редуцированная модель.** Пример раствора не является
измерением. Сходимость численного расчёта не заменяет сравнение с экспериментом.
Физическая постановка, уравнения и ограничения: [PHYSICS_RU.md](docs/PHYSICS_RU.md).
Проверки и результаты демонстрации: [VALIDATION_RU.md](docs/VALIDATION_RU.md).

## Установка и первый расчёт

Нужны Python 3.11+, GNU Fortran, GNU Make. Linux: установите `gfortran`, `make`,
`python3-venv` средствами ОС; macOS: GNU Fortran из Homebrew; Windows: WSL2/Ubuntu.
Не применяйте `-ffast-math`: он мешает обнаружению нечисловых состояний.

```bash
cd Electrospining
bash scripts/setup.sh
.venv/bin/python -m electrospin run --config configs/demo.json --out results/demo
```

В подготовленной облачной среде зависимости и компилятор уже установлены.
Каждый запуск требует **новую или пустую** папку результатов и сохраняет
фактическую конфигурацию, namelist, версии, контрольные суммы исходников и
исполняемого файла. Существующие результаты не перезаписываются.

```bash
# Ввод свойств раствора и установки через терминал, затем расчёт
.venv/bin/python -m electrospin wizard --save configs/my_solution.json --run --out results/my_solution

# Небольшой расчёт; за короткое время волокно может не достичь коллектора
.venv/bin/python -m electrospin run --config configs/quick.json --out results/quick

# Менять любые известные параметры без правки JSON: значения в СИ и синтаксисе JSON
.venv/bin/python -m electrospin run --config configs/demo.json --out results/moving \
  --set 'collector_velocity=[0.01,0]' --set voltage=12000 --set viscosity=0.4

# Повторная визуализация уже рассчитанных данных
.venv/bin/python -m electrospin report results/demo
```

Дополнительный режим с более сильным влиянием кулоновских сил:

```bash
.venv/bin/python -m electrospin run --config configs/whipping_example.json --out results/bending
```

Он показывает усиление изгиба относительно контроля без кулоновских сил,
но не является подтверждённым режимом развитого макроскопического whipping.

Откройте `results/demo/report.html` в браузере: он работает автономно, без сервера
и подключения к интернету. Внутри — вращаемая 3D-струя, анимация, укладка,
карта массы на коллекторе, диаметры и ориентация, электрическое поле и заряд.
`report.png` — статическая обзорная картинка. `needle3d.html` и `needle3d.png`
показывают 3D-реконструкцию заряда металла и жидкого мениска по рассчитанным
осесимметричным граням (не отдельное решение 3D-Пуассона). `trajectory.vtp` открывается в
ParaView и содержит конечный снимок струи с числовыми атрибутами.

## Геометрия именно шприцевой иглы

По умолчанию: **22G, наружный диаметр 0,70 мм, внутренний 0,40 мм**, выступающая
длина 10 мм. Это выбранные представительные размеры; у производителей они
различаются. В терминале вводятся диаметры, а в JSON — радиусы в метрах.

Решается осесимметричный Laplace методом конечных объёмов: полая металлическая
трубка, заполненная проводящим раствором, полусферический мениск в отверстии,
заземлённый коллектор на расстоянии `gap` от вершины мениска и цилиндрическая
стенка камеры. Заряд стали и жидкости экспортируется раздельно. Внешняя граница
камеры влияет на поле: это физическая часть геометрии, а не безразличный размер
картинки. Для сравнения с открытой установкой проверяйте увеличение `field_radius`.

Геометрия осесимметрична: **скос иглы, образование и изменение конуса Тейлора
не разрешаются**. Мениск принимается эквипотенциальным. Вблизи идеальной кромки
пиковые поле и заряд сеточно чувствительны. `field_summary.json` содержит
разрешение мениска, остаток линейной системы и баланс граничного заряда.

```bash
# Только поле и распределение заряда иглы, без динамики струи
.venv/bin/python -m electrospin field --config configs/demo.json --out results/needle
```

`field_mode="needle"` — основной режим. `uniform` полезен для контрольных задач;
он не моделирует усиление поля у иглы. `file` читает внешний осесимметричный CSV.
Не накладывайте поле, уже содержащее заряд струи, на pair-Coulomb силы ядра:
это дважды учтёт одну и ту же силу.

## Какие свойства раствора влияют на расчёт

Терминальный мастер переводит лабораторные единицы в СИ. Полный JSON позволяет
менять дополнительные свойства и численные параметры.

| Параметры JSON | Единицы | Что рассчитывается |
|---|---|---|
| `flow_rate`, `jet_radius` | м³/с, м | Скорость подачи и объём материальных сегментов |
| `polymer_fraction`, `density_polymer`, `density_solvent` | массовая доля 0…1, кг/м³ | Массы, объёмы, концентрация и инерция |
| `viscosity`, `relaxation_time` | Па·с, с | Напряжения Maxwell и вязкоупругое растяжение |
| `viscosity_exponent`, `activation_energy` | 1, Дж/моль | Зависимость вязкости от концентрации и температуры |
| `surface_tension` | Н/м | Капиллярное натяжение |
| `temperature`, `ambient_temperature`, `humidity` | К, К, доля 0…1 | Нагрев/охлаждение и испарение |
| `molar_mass`, `latent_heat`, `psat_ref`, `psat_temperature` | кг/моль, Дж/кг, Па, К | Свойства выбранного растворителя |
| `mass_transfer`, `heat_transfer`, `cp_polymer`, `cp_solvent` | м/с, Вт/(м²·К), Дж/(кг·К) | Массо- и теплообмен |
| `current` | А | **Заданный конвективный** ток, переносимый струёй |
| `conductivity`, `relative_permittivity` | См/м, 1 | Диагностика времени релаксации заряда ε₀εᵣ/K |
| `air_velocity`, `air_density`, `drag_coefficient` | м/с, кг/м³, 1 | Эмпирическое аэродинамическое сопротивление |
| `collector_velocity` | две компоненты, м/с | Перенос осевших точек плоского коллектора |

`current` в 3D — **не полный ток источника**, который может включать омическую
составляющую и ток разряда. Перенос проводимости вдоль искривлённой струи сейчас
не решается: изменение `conductivity` при фиксированном `current` меняет
диагностику, но не траекторию. `air_viscosity` тоже диагностический параметр:
сопротивление задаётся эффективным `drag_coefficient`. Пример водного раствора
нельзя превратить в модель другого растворителя одной заменой его названия —
нужны реальные давление пара, теплота испарения, реология и коэффициенты обмена.

## Укладка и изгибная неустойчивость

Поступающий раствор описан цепочкой материальных объёмов. Масса и заряд
непрерывно поступают через входной резервуар; после разбиения остаются
с материальным сегментом. Действуют внешнее поле, парные кулоновские силы,
Maxwell-напряжение, поверхностное натяжение, тяжесть и сопротивление воздуха.
Радиус следует из объёма и длины сегмента; испаряется только растворитель.

`perturbation_amplitude` и `perturbation_frequency` задают малое возмущение
подачи. **Траектория не задаётся спиралью**: дальнейшие координаты получаются из
уравнений движения. Сам по себе спиральный рисунок не доказывает линейную
неустойчивость. Проверяйте усиление возмущений, чувствительность к затравке,
сравнение `coulomb=true/false` и разрешение цепочки.

Пересечение плоскости коллектора интерполируется по времени. Осевшие точки
следуют движению коллектора, заряд передаётся идеальной земле. Карта укладки
соединяет только соседние материальные ID, достигшие коллектора; сортировка
по времени попадания не используется. Карта массы строится консервативно по
отрезкам, а не по числу попаданий. Это проекция осевой линии с разрешением
цепочки: слипание, контакт волокон, многослойная толщина и поры не рассчитываются.
Гистограмма диаметров — средние диаметры материальных сегментов при попадании.
«Сухой диаметр» предполагает удаление растворителя при неизменной длине.

## Параметрическое исследование

```bash
# Декартово произведение: четыре комбинации
.venv/bin/python -m electrospin sweep --config configs/demo.json --out results/sweep \
  --param voltage=8000,12000 --param viscosity=0.1,0.4 --workers 2

# Латинский гиперкуб: воспроизводимая выборка из диапазонов
.venv/bin/python -m electrospin sweep --config configs/demo.json --out results/lhs \
  --lhs 12 --range viscosity=0.1:0.6 --range relaxation_time=0.003:0.03 \
  --range voltage=7000:15000 --seed 42
```

Каждый случай имеет отдельную папку. `study.csv` сохраняет численные метрики,
неудачные случаи и причины. `study.html`/`study.png` сравнивают результаты;
`response3d.html` показывает вычисленные точки отклика для двух и более
варьируемых параметров. Это не выдуманная гладкая поверхность между точками.
`--reports` включает полные отчёты каждого случая. По умолчанию максимум
100 запусков; `--max-runs` меняет ограничение. При любом неудачном расчёте серия
сохраняет остальные результаты и возвращает ненулевой код завершения.

## Численное разрешение и проверки

```bash
make test PYTHON=.venv/bin/python
make test-original PYTHON=.venv/bin/python

# Отдельно поле: три сетки
.venv/bin/python -m electrospin.convergence --config configs/demo.json \
  --out results/convergence_field --field-only

# Поле + независимое уточнение dt_max и injection_interval: девять случаев
.venv/bin/python -m electrospin.convergence --config configs/demo.json \
  --out results/convergence_full
```

`dt_max` — верхний предел адаптивного шага. Ядро дополнительно ограничивает шаг
по перемещению, ускорению, упругости, испарению и изменению температуры;
падение ниже `dt_min` и исчерпание `max_steps` — ошибка, а не успешный результат.
`injection_interval` задаёт пространственное разрешение струи при заданном
расходе; `max_beads` должен вмещать весь расчёт, включая осевшие элементы.
`coulomb_softening` — длина регуляризации парного заряда, не косметическая
настройка; её чувствительность тоже надо проверять. Совпадение временного шага
не означает сходимости по цепочке или сглаживанию заряда.

| Файл | Содержание |

| `config.json`, `jet3d.nml`, `effective_jet3d.nml` | Входные и фактически прочитанные параметры |
| `manifest.json`, `run_status.txt`, `console.log` | Статус, происхождение расчёта, ошибки |

| `diagnostics.csv` | История балансов массы, полимера и заряда, шаг и максимумы |

| `field/electrode_charge.csv` | Заряд на гранях стали, жидкости, коллектора и камеры |

## Исходная модель и плазма сохранены

`make all` собирает также `build/electrospinning`. Подробности старой модели —
[original/README_RU.md](original/README_RU.md), плазмы —
[original/PLASMA_RU.md](original/PLASMA_RU.md). Их исходники не изменены.
Старый расчёт использует **дисковый электрод**; он оставлен для воспроизводимости,
сравнения и собственных проверок, а не вместо новой иглы.

```bash
mkdir -p results/original
cd original
../build/electrospinning --config config_spinning.nml --preset quick \
  --output ../results/original/
# Дополнительный короткий осесимметричный расчёт плазмы:
../build/electrospinning --config config_spinning.nml --preset quick \
  --plasma-config plasma_air.nml --output ../results/original/plasma_
```

Плазменный модуль не связан обратно с новой 3D-струёй. Для полноценного
взаимодействия разряда, пространственного заряда газа и изгибающейся жидкости
нужен отдельный согласованный 3D-расчёт, а не наложение старой плазмы на график.
Исходные лицензии таблиц плазмы сохранены в `original/plasma_data/`.
