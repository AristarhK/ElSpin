# ElSpin 0.3: где находятся нужные графики

Верхняя строка графиков заменена тремя постоянно видимыми кнопками.
Горизонтальной прокрутки вкладок больше нет.

1. **«Падение на коллектор — 2D»**. Слева показана струя в плоскости x–z
   с иглой и линией коллектора; справа — уложенная нить в плоскости x–y.
   Ползунок времени показывает только уже произошедшие попадания.
2. **«Высыхание по координате z»**. Один крупный график доли испарившегося
   исходного растворителя против расстояния от иглы z в миллиметрах.
   Показана история первого материального сегмента до выбранного времени.
   В примере изменение мало: испарилось около 0.161%, осталось 99.839%.
   Поэтому график показывает испарившуюся долю с читаемой шкалой;
   полного высыхания результат не изображает.
3. **«Число филаментов по z»**. Один крупный график N(z). Координата —
   фактическое z родительской траектории, а не накопленный путь s.
   В примере ветвление отключено, поэтому N=1. Это прямо подписано на графике.
   Кнопка **«Настроить ветвление»** открывает соответствующие параметры слева.
   Затем нужен новый расчёт с выбранными настройками. При включённом сценарии
   рост также может отсутствовать, если критерий не достигнут.

Для просмотра без запуска нового расчёта нажмите **«Открыть пример»**.
Для собственного результата — **«Открыть расчёт…»** и выберите каталог,
содержащий `analysis.json` и `trajectory.csv`.

3D, поле, диагностика, подробные профили и параметрическая сетка доступны
из списка **«Другие графики»**. Три основные кнопки остаются на экране.
Экспорт создаёт понятные файлы `fall_2d.png`, `drying_z.png`, `filaments_z.png`
и общий PDF.

## Ограничение графика N(z)

N(z) относится к отдельному, некалиброванному популяционному сценарию.
Настоящие дочерние 3D-траектории не рассчитываются. Число пересечений одной
извивающейся цепочки — другая величина; оно осталось в дополнительном
графике «Филаменты и ветвление». Увеличение N не рисуется искусственно.

CSV новых расчётов содержит `z_m`; для результатов версии 0.2 координата
восстанавливается по сохранённой истории родительской частицы. Изменять
или пересчитывать старые файлы для этого не требуется.
