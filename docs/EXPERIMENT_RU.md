# Эксперимент и прогноз — ElSpin 0.5

В основном окне нажмите **«Эксперимент и прогноз…»**. Окно работает локально
в Ubuntu и Windows; сайт и подключение к Интернету для обработки не нужны.
Таблица первоначально пустая. Приложение не выдаёт расчётные или синтетические
точки за измерения.

## Ввод серии

1. Укажите название, источник, марку раствора и способ измерения. Параметры
   режима сначала скопированы из основного окна: **исправьте их по условиям
   опыта**. Для водного раствора «пары растворителя, %» — относительная
   влажность воздуха. Для другого растворителя это насыщенность именно его
   парами, а не влажность по воде.
2. Выберите величину: среднее число дочерних струй, процент испарившегося
   исходного растворителя или процент оставшегося исходного растворителя.
   Это отдельные серии; смешивать их в одном столбце нельзя.
3. Введите `z, значение, σ` вручную, вставьте столбцы из Excel либо загрузите
   CSV. `z` — осевое расстояние от иглы в миллиметрах, а не длина изгибающейся
   траектории. Повторные координаты допустимы. Вставка таблицы заменяет
   содержимое окна; отдельную ячейку также можно редактировать.
4. `σ` необязательна: стандартная неопределённость соответствующего значения,
   в тех же единицах. Для среднего по кадрам нужна неопределённость среднего
   с учётом корреляции кадров. Это не ширина доверительного интервала.
   Заполняйте столбец для всех строк либо оставляйте полностью пустым.
5. Выберите зависимость и нажмите **«Построить зависимость и проверить»**.

CSV допускает заголовок `z_mm` либо `z_m` (метры автоматически переводятся в
миллиметры), запятые как разделители с десятичной точкой либо `;` с десятичной
запятой. Пустые шаблоны лежат в `templates/`. Значения N могут быть дробными:
модель оценивает среднее, а не обязательно целое число струй в одном кадре.

Для подбора с фиксированным началом нужно хотя бы 5 различных координат,
с подбором начала — 6. Это технический минимум. Практически полезны 8–12
координат с независимыми повторами, включая область начала роста и плато.
Число точек само по себе не гарантирует точность.

**Что считать дочерней струёй.** Измеряйте одновременно существующие ветви
в заданном сечении и фиксируйте правило подсчёта. Виток одной изгибающейся
струи, пересечение траектории и несколько уже уложенных нитей не являются
доказательством рождения дочерних струй. Если двумерная съёмка не позволяет
их различить, называйте величину наблюдаемым числом пересечений и используйте
интерполяцию; не интерпретируйте её как физическое ветвление.

**Что считать высыханием.** Вводится 100·m_s(z)/m_s(0) либо
100·[1−m_s(z)/m_s(0)], где m_s — масса растворителя в одном и том же
материальном объёме. Это не массовая доля воды в текущем влажном растворе.
При сохранении нелетучего вещества массовую долю растворителя w_s можно
пересчитать: m_s(z)/m_s(0) = [w_s(z)/(1−w_s(z))]·[(1−w_s(0))/w_s(0)].
При добавке BN нелетучая масса включает полимер и наполнитель.

## Используемые зависимости и допущения

**Модель с насыщением** использует f(z)=1−exp[−max(z−z₀,0)/L], L>0.
Для числа дочерних струй:

N(z) = [1 + (N∞^(3/2)−1)·f(z)]^(2/3), N∞≥1.

Это эмпирическое замыкание. Мотивация степени 3/2: при равном делении потока
между N одинаковыми ветвями, неизменной скорости и суммарных расходе и заряде
радиус ветви пропорционален N^(−1/2), погонный заряд — N^(−1), а отношение
электрического давления к капиллярному — N^(−3/2). **Этот масштабный аргумент
не определяет скорость рождения ветвей.** Экспоненциальное приближение к
плато — проверяемое на данных предположение, а не выведенный из него закон.
Модель не учитывает слияние, исчезновение, неодинаковый расход ветвей и
различия их траекторий; заметное падение N требует другой модели/интерполяции.

Для высыхания E(z)=E∞·f(z), 0≤E∞≤100%; оставшийся процент S(z)=100−E(z).
Это интегральная эмпирическая зависимость для одной серии, **не замена**
тепломассообменных уравнений расчётного ядра. Полное высыхание не навязывается.

Начало z₀ можно задать или подобрать. По умолчанию z₀=0; при подборе оно
неотрицательно. До начала предполагается N=1, E=0. Если данные этого не
поддерживают, проверьте происхождение координаты или выберите интерполяцию.
Модель не может определить начало ветвления за пределами измеренного участка.

**PCHIP** — сохраняющая форму кусочно-кубическая интерполяция внутри данных.
В повторных координатах используются средние, с весами 1/σ² при заданной σ.
Она допускает немонотонность, не задаёт физический механизм и не
экстраполирует. Полоса неопределённости для этой интерполяции не строится.

Условия U, Q, температура, влажность, состав и протокол сохраняются как
описание опыта. **Они не являются дополнительными входами регрессии.**
Одна серия предсказывает зависимость по z только для своих условий.
Для переноса на другие режимы нужна отдельная модель и серии при разных
U/Q/составах; окно не делает такой перенос автоматически.

## Проверка и неопределённость

Верхний график показывает введённые точки, среднюю зависимость и, когда
доступна, условную bootstrap-полосу средней кривой. Нижний показывает остатки
подбора и ошибки исключённых координат. RMSE и MAE приводятся в единицах
выбранной величины. Малый остаток на обучающих точках ещё не означает
хороший прогноз.

При проверке целая координата со всеми повторами исключается из обучения,
модель подбирается заново и предсказывает исключённые измерения. Так повторы
одной координаты не оказываются одновременно в обучении и проверке.
Проверяются все координаты до 25; для большей таблицы — 25 равномерно
выбранных координат. Для PCHIP крайние координаты проверить нельзя: они
оказываются вне оставшегося диапазона. Пропуски и причины сохраняются.
Коррелированные измерения из одной съёмки всё равно не заменяют независимую
контрольную серию. Если по этим же ошибкам выбирают модель, для итоговой
оценки точности также нужны новые, заранее отложенные измерения.

Bootstrap для модели насыщения: при заданной σ добавляется гауссов шум с
этой σ; без неё используется wild bootstrap остатков со случайными знаками.
Кривые повторно подбираются. Показаны точечные процентили 2.5 и 97.5 при
не менее 20 успешных повторов. Это **условная полоса неопределённости средней
кривой**, не гарантированный диапазон отдельного опыта и не учёт всей
ошибки физической модели. Без σ и при практически нулевых остатках полоса
не показывается: неопределённость измерения неизвестна.

При постоянном N=1 программа не делает вывод о невозможности ветвления
дальше. Параметры насыщения не определяются; экстраполяция блокируется.
Численная проверка также блокирует её при недостаточном ранге нормированного
якобиана, числе обусловленности ≥10⁴, почти нулевой чувствительности либо
достигнутой границе параметра. Это защитная диагностика, не доказательство
физической идентифицируемости. Численные границы: L от 10⁻⁴ до 10⁴ ширин
измеренного диапазона (не менее 1 мм); N∞≤max(1000,100·max N). Достижение
границы не интерпретируется как измеренное плато.

## Прогноз и сохранение

Введите z справа и нажмите **«Рассчитать точку»**. По умолчанию координата
должна лежать внутри измеренного диапазона. Экстраполяция допускается только
после отдельного включения, для модели насыщения с численно определимыми
параметрами. Она отмечается пунктиром и предупреждением; полоса за пределами
измерений не рисуется. Допустимость такой экстраполяции остаётся гипотезой.

«Сохранить серию…» сохраняет исходные точки, условия и настройки. При открытии
серии подгонка пересчитывается по нажатию кнопки; сохранённые численные
результаты не подменяют измерения. Существующий файл не перезаписывается.
Закрытие и повторное открытие окна в одной сессии сохраняет таблицу в памяти.

Экспорт создаёт новый каталог с графиком PNG/PDF, `forecast.csv`,
`validation.csv`, полной моделью и диагностикой JSON, исходной серией JSON,
текстовой сводкой и запрошенной точкой, если она рассчитана. CSV прогноза
содержит измеренный диапазон; отдельная экстраполированная точка помечена
в `queried_point.json`. Изменение точек, условий или настроек сбрасывает
предыдущий прогноз, чтобы он не сохранялся под новым режимом.

Реальные экспериментальные данные пока не предоставлены. Поэтому точность
для ПВС–вода и фактическая зависимость N(z) этой функцией ещё не установлены.
Автотесты используют явно синтетические данные и проверяют программную
реализацию, а не физическую адекватность гипотезы насыщения.
