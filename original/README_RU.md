# Электроформование: исправленный расчёт на Fortran 2008

Это переработка исходного `program electrospinning (2).txt`. Основной файл —
`electrospinning.f90`. Для самого расчёта нужен только компилятор Fortran;
Python используется для независимых проверок, сравнения сеток и графиков.

**Добавлен плазменный модуль для воздуха при 1 атм:** уравнения электронов,
положительных/отрицательных ионов, энергии электронов и согласованное поле газа.
Подробная постановка и ограничения — в [PLASMA_RU.md](PLASMA_RU.md).
Он включается командой `./electrospinning --config config_spinning.nml --preset fine --plasma-config plasma_air.nml`.
Для него требуется приложенный файл `air_transport.csv`.

**Что означает «корректный результат».** Программа проверяет сходимость и
балансы выбранной редуцированной модели. Совпадение с экспериментом требует
параметров вашей установки и раствора. Приложенный конфиг — явно обозначенный
пример водного раствора, а не восстановленные экспериментальные данные.

## Быстрый запуск

Linux / macOS с GNU Fortran:

```bash
gfortran -O2 -std=f2008 -ffree-line-length-none electrospinning.f90 -o electrospinning
./electrospinning --config config_spinning.nml
./electrospinning --config config_spinning.nml --preset heavy
```

Windows, если `gfortran` уже доступен в терминале:

```powershell
gfortran -O2 -std=f2008 -ffree-line-length-none electrospinning.f90 -o electrospinning.exe
.\electrospinning.exe --config config_spinning.nml --preset heavy
```

Не компилируйте текст как fixed-form `.f`: нужен free-form файл `.f90`.
Ключ `-ffast-math` не используйте: он мешает проверкам конечности чисел.

Вариант с Make:

```bash
make
make test
make study
```

Подробные проверки с контролем индексов и арифметических исключений:

```bash
gfortran -O2 -g -std=f2008 -ffree-line-length-none -fcheck=all \
  -ffpe-trap=invalid,zero,overflow -fbacktrace electrospinning.f90 -o electrospinning_debug
./electrospinning_debug --self-test
python3 tests/verify.py --exe ./electrospinning_debug
```

## Сетки и более тяжёлый расчёт

| Режим `--preset` | Ячейки поля, Nr × Nz | Узлы струи, Nj |
|---|---:|---:|
| quick | 64 × 96 | 201 |
| standard | 96 × 160 | 401 |
| fine | 160 × 256 | 801 |
| heavy | 256 × 400 | 1601 |

Сетка поля содержит настоящие двумерные контрольные объёмы: в режиме heavy их
102 400 вместо 4 800 в исходнике. Она сгущена к оси и эмиттеру. У струи своя
осевая сетка. Радиальная сетка поля охватывает и микрометровую струю, и большую
камеру. Сеточные размеры можно задать непосредственно в `.nml`; флаг `--preset`
переопределяет только `Nr`, `Nz`, `Nj` после чтения файла.

```bash
python3 mesh_study.py --config config_spinning.nml --out mesh_study
```

Скрипт запускает четыре режима с одинаковой физикой, создаёт отдельную папку
для каждого и `mesh_convergence.csv`. Изменение результата между сетками —
оценка сеточной чувствительности; оно не оценивает ошибки свойств материала,
геометрии или самой модели. Из-за границы дискового электрода сходимость может
быть немонотонной. Проверяйте также поле у эмиттера и весь профиль, особенно
при смене геометрии или возникновении предупреждений.

Чем больше `stretch_r`, тем мельче первая радиальная ячейка. Не нужно повышать
сгущение без проверки всей сетки: чрезмерное сгущение ухудшает обусловленность.
В `diagnostics.csv` есть отношение минимального радиуса струи к ширине первой
ячейки поля. При значении менее 3 программа предупреждает о слабом разрешении
поперечного заряда. Это эвристическая проверка, а не доказательство точности.

## Что исправлено относительно исходника

- Исключено искусственное уменьшение радиуса множителем с `alpha_whip`.
  Радиус теперь определяется расходами полимера, растворителя и скоростью.
- Вязкость входит в уравнение импульса через продольное напряжение `3 eta du/dz`.
  Поверхностное натяжение входит в капиллярную силу; добавлена диэлектрическая
  составляющая силы Максвелла в приближении тонкой струи.
- Вместо разных несовместимых формул заряда используется один сохраняющийся
  ток: сумма омической и конвективной составляющих.
- Испаряется только растворитель. Расход нелетучего полимера постоянен.
  Отслеживаются концентрация и вязкость; охлаждение связано со скрытой теплотой.
- Температура и радиус не принудительно обрезаются для получения красивого ответа.
  Выход из области модели и отсутствие сходимости дают ошибку.
- Для осесимметричного Пуассона использованы реальные объёмы колец и потоки через
  грани. Заряд консервативно переносится на сетку, включая первую ячейку у оси.
- Сходимость поля проверяется по фактической невязке линейной системы.
  Решатель PCG использует модифицированное неполное разложение Холецкого.
- Внешний цикл контролирует изменение поля, скорости и источника заряда;
  финальный результат создаётся только после сходимости.
- Проверяются диапазоны входных данных, NaN/Inf, положительность скорости,
  открытие файлов и исчерпание лимитов итераций. Смена полярности учитывается
  одновременно в поле и токе.
- Удалены неподтверждённые формулы `ne ~ E^4`, `Te = 1..5 eV` и произвольная
  «нейтрализация» заряда. Их численные значения нельзя получить из уравнения
  Пуассона. Вместо них есть отдельный приблизительный индикатор короны.

## Физическая модель

### Геометрия и поле

Осесимметричная область: `0 <= r <= R_max`, `0 <= z <= Z_max`.
На верхней границе расположен **дисковый эмиттер** радиуса `R_needle` с
потенциалом `V_voltage`. Остальная верхняя граница изолирована. Коллектор
при `z = Z_max` заземлён, на оси поток равен нулю. Боковая граница задаётся:

- `side_boundary='grounded'` — заземлённая цилиндрическая стенка;
- `side_boundary='insulating'` — нулевой нормальный поток поля.

Это две разные физические постановки. Изолирующая граница не является
автоматической заменой открытого пространства. Длина и форма металлической
иглы и конус Тейлора не восстанавливаются из единственного радиуса.

Решается `-div(grad(phi)) = rho_charge / eps0` в цилиндрических координатах.
Скалярная проницаемость области поля равна проницаемости воздуха. Собственный
заряд струи сглажен по её сечению; его интеграл по кольцам точно равен линейному
заряду. Это осреднение, а не разрешение двойного электрического слоя.

Осевое поле интерполируется к поверхности тонкой струи. При
`space_charge=.true.` профиль заряда и поле согласуются внешними итерациями.
Поляризация жидкости включена в продольную силу в ведущем приближении тонкой
струи; полноценная задача с разрывом диэлектрической проницаемости на подвижной
границе не решается. Эту составляющую можно отключить: `polarization_force=.false.`.

### Расходы и заряд

Для массовых расходов полимера `mp` и растворителя `ms(z)`:

```text
mp = const
Q(z) = mp/rho_polymer + ms(z)/rho_solvent
A(z) u(z) = Q(z)
a(z) = sqrt(A(z)/pi)
I = lambda(z) u(z) + conductivity(z) A(z) E(z) = const
q_surface(z) = lambda(z) / (2 pi a(z))
```

Здесь плотности чистых компонентов постоянны; объёмы считаются аддитивными.
`polymer_fraction` — начальная МАССОВАЯ доля. `Q_pump` — объёмный расход всего
исходного раствора. Отрицательный поверхностный заряд при положительном
напряжении не скрывается: это повод проверить ток, проводимость и входной радиус.

`Jet_current_A >= 0` задаёт модуль тока, его знак следует полярности напряжения.
Ток через струю не включает паразитные утечки и ток газового разряда. При
`Jet_current_A=-1` применяется только оценка
`current_coefficient * sqrt(Gamma * Conductivity * Q_pump)` с предупреждением.
Она не определяет ток произвольной установки без калибровки и не проверяет запуск
конусно-струйного режима. При нулевом напряжении принятый ток равен нулю.

### Движение

Используется стационарный баланс для тонкой ньютоновской струи:

```text
(mp + ms) du/dz = d(3 eta A du/dz)/dz + pi Gamma da/dz
                 + lambda E + A eps0 (Epsilon_r - 1) E dE/dz
                 + [(mp + ms)/u - rho_air A] g_z
                 - pi rho_air Cd_drag a (u - u_air) |u - u_air|
```

Член поляризации включается указанным выше флагом. Испарившаяся масса уносит
локальную осевую скорость, поэтому её вклад сокращается при переходе к этой
форме уравнения импульса. Вход: `u(0)=Q_pump/(pi*jet_radius_in**2)`.
Выход: нулевое ньютоновское продольное напряжение, `du/dz=0`.
Скорость коллектора здесь не задаётся. `Cd_drag` — эффективный коэффициент
осевого поверхностного трения, требующий калибровки.

Вязкость зависит от концентрации и температуры:

```text
eta = Viscosity * (w/polymer_fraction)**viscosity_exponent
      * exp(activation_energy/R * (1/T - 1/T_air_K))
```

Этот закон — настраиваемое приближение, а не универсальная реология полимеров.
Проводимость может зависеть от объёмной доли растворителя степенным законом
`conductivity_exponent`; ноль означает постоянную проводимость.

### Испарение и энергия

Поток испарения определяется коэффициентом массопереноса `k_mass`, разностью
поверхностной и окружающей концентраций пара и приближённой активностью
растворителя, равной его объёмной доле. Конденсация исключена; отрицательный
испарительный поток принимается равным нулю как часть этой постановки.
Давление насыщения задаётся интегральной формой Клаузиуса — Клапейрона с
постоянной скрытой теплотой относительно `psat_ref`, `T_psat_ref`.

Тепловой баланс включает теплообмен с воздухом, скрытую теплоту испарения,
омический нагрев `conductivity A E**2` и вязкую диссипацию `3 eta A (du/dz)**2`.
Расход растворителя и температура интегрируются неявно; положительность
остатка растворителя обеспечивается решением баланса с ограниченным поиском
корня, а не искусственным удалением отрицательных значений.

Схема струи первого порядка по оси; электростатическая схема проверена на
квадратичной задаче с известным решением. Фактическую точность всей постановки
нужно проверять сравнением сеток, а не только малой невязкой.

## Входные данные, которые особенно важно заменить

Все числа в SI, кроме явно отмеченных температуры воздуха и влажности.

| Параметр | Смысл и единицы |
|---|---|
| `V_voltage`, `Z_max` | Напряжение, В; расстояние до коллектора, м |
| `R_needle` | Радиус дискового электрода, м; приближение геометрии эмиттера |
| `jet_radius_in` | Радиус струи ПОСЛЕ конуса Тейлора, м; обычно отличается от радиуса иглы |
| `Q_pump` | м³/с; `1 мл/ч = 1e-6/3600 м³/с` |
| `Gamma`, `Viscosity` | Н/м; динамическая вязкость исходного раствора, Па·с |
| `Conductivity`, `Epsilon_r` | См/м; относительная проницаемость жидкости |
| `Jet_current_A` | Модуль тока струи, А; `-1` — приближённая оценка |
| `polymer_fraction` | Массовая доля полимера, от 0 до 1 |
| `T_air`, `Humidity` | °C; процент насыщения окружающего газа паром выбранного растворителя |
| `rho_polymer`, `rho_solvent` | Плотности чистых компонентов, кг/м³ |
| `cp_polymer`, `cp_solvent` | Дж/(кг·К) |
| `thermal_conductivity_fluid` | Вт/(м·К), для проверки допустимости единой температуры сечения |
| `latent_heat`, `molar_mass` | Дж/кг; кг/моль |
| `psat_ref`, `T_psat_ref` | Па; К |
| `activation_energy` | Дж/моль |
| `k_mass`, `h_conv` | м/с; Вт/(м²·К); коэффициенты должны соответствовать условиям обтекания |
| `g_z`, `air_velocity` | м/с² вдоль оси; м/с вдоль оси |

Для органического растворителя относительная влажность ВОДЫ не задаёт его
парциальное давление. Переопределите `Humidity` как процент насыщения именно
выбранного растворителя, а также его молярную массу, теплоту, давление пара и
остальные свойства. Строка `solvent_name` — подпись, она не подставляет свойства
из базы. Встроенной базы растворителей нет.

Параметр `Rho_fluid=-1` включает расчёт плотности смеси по компонентам.
Если указано положительное значение, обе плотности приравниваются к нему для
совместимости с приближением постоянной плотности старого кода.

## Старый `config_spinning.txt`

Поддерживается прежний формат: 11 обязательных чисел по одному в строке и
3 необязательных: `alpha_whip`, `Cd_drag`, `h_conv`. `alpha_whip` считывается,
но не используется. Порядок обязательных значений сохранён:

```text
V_voltage, Z_max, R_needle, Gamma, Viscosity, Q_pump,
Epsilon_r, Conductivity, Rho_fluid, T_air, Humidity
```

Для явного чтения старого файла:

```bash
./electrospinning --config config_spinning.txt --preset fine
```

В старом формате отсутствуют радиус струи после конуса и свойства полимера / 
растворителя. Поэтому радиус струи принимается равным радиусу иглы, а недостающие
свойства — из примера с предупреждениями. Такая постановка может не иметь
приемлемого стационарного решения. Для физических расчётов перенесите параметры
в `.nml` и укажите фактический радиус выходящей струи и свойства раствора.

Без `--config` программа сначала ищет `.nml`, затем старый `.txt`, затем
использует демонстрационные значения. Явно указанный отсутствующий файл даёт ошибку.

## Пределы применимости

- Нет расчёта конуса Тейлора, запуска струи, распада на капли, трёхмерного whipping,
  вязкоупругости или движения коллектора. Осесимметрия сама по себе исключает
  настоящую изгибную неустойчивость. Нарисованная спираль не была бы её расчётом.
- Конечный диаметр — диаметр ЖИДКОЙ / ЧАСТИЧНО ВЫСУШЕННОЙ струи в рамках этой модели.
  `dry_diameter_same_speed_m` — условный диаметр при последующем удалении всего
  растворителя с сохранением конечной скорости. Это отдельная оценка, а не
  предсказание реального диаметра нанонити после whipping.
- Отверждение не подменяется замораживанием массивов. При высокой доле полимера
  нужно заменить ньютоновскую модель экспериментальной реологией / моделью
  стеклования; программа выдаёт предупреждение при массовой доле выше 0.65.
- Температура и состав считаются однородными по сечению. Радиальная диффузия
  растворителя не решается. Проверка Biot относится только к теплообмену.
- Кипение исключено. Температурный интервал численного поиска 200..420 К —
  техническая область решателя; он не подтверждает пригодность свойств конкретного
  раствора во всём диапазоне. Для воды также проверяйте отсутствие замерзания.
- Формула Пика применена только как приблизительный индикатор по полю у оси
  эмиттера и его радиусу. Поправка плотности воздуха имеет правильную зависимость
  `(p/p_ref)*(T_ref/T)`. Формула исходно относится к цилиндрическим проводникам,
  поэтому для диска и реальной иглы это не точный критерий зажигания.
  Край идеального диска имеет усиленное поле, и осевая проверка не исключает корону
  на краю. Без `--plasma` газовый заряд, ионизация, рекомбинация, `ne` и `Te`
  не вычисляются. Опциональный плазменный блок описывает короткий переходный
  процесс в отдельной области у оси; см. `PLASMA_RU.md`. Он не подтверждает
  стационарную корону на краю диска или на реальной игле.

## Проверки и источники

Журнал выполненных проверок находится в `validation/tests.log`; сеточное
сравнение и исходные CSV — в `validation/mesh`. Проверены аналитический
конденсатор, решение Пуассона с заданной правой частью, сохранение заряда при
осевом осреднении, отсутствие искусственного утонения без сил, гравитационный

Физические ориентиры; реализация является описанной выше редуцированной моделью,
а не полным воспроизведением перечисленных статей:

1. N. B. Ismail et al., *Simplified modeling of the electrospinning process from
   the stable jet region to the unstable region for predicting the final nanofiber
   diameter*, J. Appl. Polym. Sci. (2016), DOI
   [10.1002/app.44112](https://doi.org/10.1002/app.44112).
   Балансы заряда и движения тонкой струи, в том числе диэлектрическая сила.
2. M. Wieland et al., *An Efficient Numerical Framework for Fiber Spinning
   Scenarios with Evaporation Effects in Airflows*,
   [arXiv:1805.09598](https://arxiv.org/abs/1805.09598).
   Согласование движения, состава и температуры при испарении; в статье также
   рассмотрена радиальная диффузия, которой в этом коде нет.
3. S. V. Fridrikh et al., *Controlling the Fiber Diameter during Electrospinning*,
   Phys. Rev. Lett. 90, 144502 (2003),
   [10.1103/PhysRevLett.90.144502](https://doi.org/10.1103/PhysRevLett.90.144502).
   Показывает отдельную роль изгибной стадии; её терминальный диаметр здесь
   не подменяется диаметром прямой струи.
4. *Measurement of Corona Discharges under Variable Geometry, Frequency and
   Pressure Environment*, Sensors 22, 1856 (2022),
   [10.3390/s22051856](https://doi.org/10.3390/s22051856).
   Экспериментальные ограничения переноса формулы Пика между геометриями.
