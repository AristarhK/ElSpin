# Добавленный расчёт электронов и ионов в атмосферном воздухе

Итоги временной и пространственной проверки, включая остающуюся чувствительность
локального максимума Te, приведены в [PLASMA_VALIDATION_RU.md](PLASMA_VALIDATION_RU.md).

Теперь в программе есть **новые уравнения** для концентраций электронов,
положительных/отрицательных ионов и плотности энергии электронов. Заряд газа
входит в Пуассон и изменяет поле на каждом шаге времени. Температура электронов
вычисляется из решаемой энергии, а не задаётся формулой вида `1 + 4 tanh(E)`.

## Запуск

Сборка выполняется той же командой; весь Fortran-код находится в одном `.f90`:

```bash
gfortran -O2 -std=f2008 -ffree-line-length-none electrospinning.f90 -o electrospinning
./electrospinning --config config_spinning.nml --preset fine --plasma-config plasma_air.nml
```

Windows:

```powershell
gfortran -O2 -std=f2008 -ffree-line-length-none electrospinning.f90 -o electrospinning.exe
.\electrospinning.exe --config config_spinning.nml --preset fine --plasma-config plasma_air.nml
```

Рядом должны лежать `config_spinning.nml`, `plasma_air.nml` и `air_transport.csv`.
Путь к таблице можно переопределить параметром `p_transport_file`. Python для
самого расчёта не нужен. Без `--plasma` / `--plasma-config` работает прежний
расчёт жидкой струи. Ключ `--preset` меняет сетку жидкой стадии; сетка газа
задаётся отдельно в `plasma_air.nml`.

Проверки и графики:

```bash
./electrospinning --plasma-test
python3 tests/verify_plasma.py --exe ./electrospinning
python3 plot_plasma.py --out plasma_results.png
python3 plasma_mesh_study.py --exe ./electrospinning
```

## Газ, геометрия и время

Для обычного атмосферного воздуха принято стандартное приближение: сухая смесь
80% N2 и 20% O2 при 101325 Па. Температура газа берётся из `T_air` основной
конфигурации. Влажность и пары растворителя **не входят в кинетику плазмы** этой
версии. Реальная влажная смесь требует других транспортных и реакционных данных.
Таблица рассчитана около комнатной температуры; поддерживается диапазон 280..320 К
и давление в пределах 1% от 1 атм.

`plasma_quick.nml` задаёт быстрый просмотр 48×96, `plasma_air.nml` — более
подробную сетку 256×256, `plasma_heavy.nml` — дополнительное радиальное сгущение
512×256. Наибольшие значения Te у поверхности требуют отдельной проверки сетки;
число точек само по себе не является подтверждением точности максимума.

Сначала рассчитывается стационарная струя. Затем запускается короткий газовый
процесс в отдельной вложенной области `0 <= r <= p_radius`, `0 <= z <= p_length`.
По умолчанию это 0.2 мм по радиусу и 2 мм по оси. Потенциалы на внешних границах
этой области берутся из решения большой задачи. Ось имеет условие симметрии.
Область находится под дисковым эмиттером и исключает его идеальный острый край.
Она не охватывает всю камеру и боковую поверхность реальной металлической иглы.

На коротком интервале по умолчанию 0.2 нс скорость, форма и заданный заряд
струи считаются неизменными. Время ограничено относительно времени пролёта
струи и её диэлектрической релаксации. Газовое поле меняется самосогласованно;
жидкая стадия во время этого короткого импульса повторно не решается.

Газовые ячейки внутри струи исключены из переноса частиц. Поверхность струи,
электрод и внешние границы области поглощают частицы. Их потери и уносимый заряд
учитываются в балансе. Накопление поглощённого заряда на жидкости отдельно не
решается; для сильного или длительного разряда такое приближение нужно заменить.

Для электронов использовано тепловое поглощающее условие Робина:
поток пропорционален плотности и `sqrt(kB Te/(2 pi me))`. Поток энергии на стенку
соответствует энергии уносимого максвелловского электрона `2 kB Te`, то есть
4/3 локальной средней энергии. Это дополнительное приближение граничного
распределения, исключающее принудительное обнуление электронной плотности
непосредственно на газовой стороне стенки.

## Уравнения

Положительные и отрицательные ионы представлены двумя эффективными компонентами
`n_positive` и `n_negative`; отдельные N2+, O2+, O4+, O2− и другие кластерные ионы
в этой первой модели не разделяются.

```text
∂ne/∂t + div(Γe) = (νion - νatt) ne - βei ne n+
∂n+/∂t + div(Γ+) = νion ne - βei ne n+ - βii n+ n−
∂n−/∂t + div(Γ−) = νatt ne - βii n+ n−

Γe = -μe ne E - grad(De ne)
Γ± = ±μ± n± E - grad(D± n±)

-div(eps0 grad(phi)) = rho_jet + e(n+ - ne - n−)
E = -grad(phi)
```

Частоты ионизации и прилипания включают столкновения с N2/O2, в том числе
трёхчастичное прилипание. В `air_transport.csv` уже включены доли компонентов:

```text
νion = N ki
νatt = N ka2 + N² ka3
N = pressure_air / (kB Tgas)
```

Число положительных зарядов минус число отрицательных сохраняется реакциями.
Эффективные ионные подвижности и коэффициенты рекомбинации настраиваются в
`.nml`; их значения являются редуцированными параметрами, а не заменой полной
ионной химии воздуха.

Решается также уравнение плотности энергии `w` в эВ/м³:

```text
∂w/∂t + div(Γw) = -Γe · E - ne N L(ε) - потери при рекомбинации
Γw = -με w E - grad(Dε w)
ε = w / ne
Te [эВ] = 2 ε / 3
με = (5/3) μe; Dε = (5/3) De     [по умолчанию]
```

`Te` здесь — **эффективная температура, соответствующая средней энергии**.
Это не означает, что распределение электронов по энергиям является максвелловским.
Множитель 5/3 в переносе энергии — дополнительное стандартное приближение потока.
Отдельная пространственно-временная функция распределения не решается.
Если электронов нет, `Te_defined=0`; значение `Te_eV=0` в CSV тогда служит
маркером отсутствия определённой температуры, а не утверждением о плазме при 0 эВ.

### Откуда взяты коэффициенты и потери энергии

Использованы опубликованные таблицы BOLSIG+/Phelps для сухой смеси 80/20 из
проекта Afivo-streamer. Исходный файл сохранён в `plasma_data/air_light_example_v0.txt`.
Его Git blob SHA: `e3c3027260ed11716fe8e377b8070cce72cc99fa`.
Скрипт `plasma_data/build_table.py` проверяет этот SHA и воспроизводит CSV.
Важное преобразование `FACTOR: 1e-6` для трёхчастичного прилипания применено;
пропуск этого множителя дал бы ошибку на шесть порядков.

Таблица задаёт среднюю энергию, электронную подвижность, диффузию и скорости
реакций как функции приведённого поля. В модуле они параметризуются средней
энергией. Потери энергии не заданы произвольно: они восстановлены из однородного
энергетического равновесия этих таблиц с учётом рождения и гибели электронов:

```text
L(ε) = (μe N) (E/N)eq² - ε (ki - ka2 - N ka3)
```

Это **замыкание, согласованное со стационарной кривой электронного роя**.
Оно не является независимым суммированием всех возбуждений, диссоциаций и
упругих потерь в подробной химической модели. Тест однородного равновесия
проверяет именно его согласованность с исходными таблицами. Для публикационной
модели конкретного разряда желательно заменить его непосредственно рассчитанными
энергетическими коэффициентами для выбранного набора сечений и смеси.

Исходные данные начинаются с 1 Td. Ниже добавлено явно заданное согласование
с тепловым пределом при температуре газа. Выше максимальной энергии/поля таблицы
экстраполяция исключена: расчёт останавливается. При локальном E/N выше 500 Td
выдаётся предупреждение о необходимости проверки дрейфово-диффузионного
приближения, даже если точка ещё находится внутри таблицы до 1300 Td.

## Начальные условия: почему они нужны

Проверочный пример содержит электронно-ионную затравку: положительных ионов
первоначально столько же, сколько электронов. Её амплитуда `p_seed_ne=1e17 м⁻³`
выбрана для демонстрации развития лавины и влияния заряда на поле; это **не
измеренная концентрация естественного атмосферного фона**. Положение и размеры
затравки задаются отдельно. Начальная энергия соответствует равновесной кривой
таблицы в начальном поле; затем она изменяется по решаемому уравнению энергии.

Абсолютное значение ne зависит от затравки, времени и механизмов рождения
электронов. Фото-ионизация, вторичная эмиссия, отлипание электронов и внешняя
предыонизация в виде источника здесь не моделируются. При нулевой начальной
концентрации и отсутствии источников ne остаётся нулём — это проверяется тестом.

Пример описывает переходный процесс с заданной затравкой. Он не доказывает
самостоятельное зажигание и устойчивое существование короны в эксперименте.

## Численная схема и файлы

Перенос дискретизован консервативным методом конечных объёмов в цилиндрических
координатах. На гранях используется схема Шарфеттера — Гуммеля, сохраняющая
положительность и правильно воспроизводящая больцмановское равновесие. По
направлениям выполняются неявные шаги с трёхдиагональными системами. Реакции
сохраняют заряд, энергетический шаг решается неявно по монотонному замыканию.
Мощность поля вычисляется из гранных потоков электронов и перепадов потенциала,
включая диффузионный вклад. Уравнение Пуассона решается на каждом шаге времени.

Порядок схемы по времени — первый. Малая невязка баланса не означает малую ошибку
пространственной сетки или истинность химического замыкания. Необходимы проверки
шага, сетки, размеров вложенной области и граничных условий.

| Файл | Содержимое |
|---|---|
| `plasma_initial.csv` | Начальные ne, n+, n−, энергия, Te и поле |
| `plasma_final.csv` | Те же величины в момент завершения |
| `plasma_history.csv` | Максимумы ne/Te, числа частиц, балансы и обратное влияние на потенциал |
| `plasma_summary.txt` | Итог, параметры проверки и ограничения |
| `effective_plasma_config.nml` | Реально использованная конфигурация газа |

Сначала проверяйте `run_status.txt`: успешный полный запуск содержит
`NUMERICALLY_CONVERGED` и `PLASMA_TRANSIENT_COMPLETED`. Состояние `RUNNING_PLASMA`
означает, что газовый процесс ещё не завершился. Старые итоговые CSV не являются
результатом нового неудачного запуска. Жидкая стадия описана отдельно в
`run_summary.txt`; газовая — в `plasma_summary.txt`.

## Проверки

- Устойчивое вычисление функции Бернулли, включая большие аргументы.
- Больцмановское равновесие гранного потока Шарфеттера — Гуммеля.
- Однородное энергетическое равновесие опубликованных таблиц.
- Сохранение заряда при ионизации, прилипании и рекомбинации.
- Сохранение частиц в замкнутой неравномерной цилиндрической сетке.
- Баланс поглощённых частиц на стенках и положительность решения.
- Уменьшение ошибки при последовательном уменьшении шага времени.
- Отсутствие выдуманной плазмы при нулевой затравке.
- Отказ с понятным статусом при неверной геометрии или отсутствии таблицы.

Журнал — `validation/plasma/tests.log`; пример — файлы с префиксом `demo_` в
`validation/plasma`; этот быстрый пример соответствует `plasma_quick.nml`.
Пространственное сравнение — `validation/plasma/mesh` и `validation/plasma/radial`.
