# ElSpin 0.5 — электроспиннинг, эксперимент и прогноз

Настольное приложение Qt для Ubuntu и Windows 10/11 x64, без сайта и сервера.
Аппаратная схема пользователя: неподвижная игла над плоским коллектором
по мотивам **Douglas Miller / OpenESpin**, винтовой шприцевой насос с кареткой
по мотивам **MIT Critical Matter**. Роботизированная рука не используется.

Актуальная расчётная записка: [PHYSICS_AUDIT_V04_RU.pdf](docs/PHYSICS_AUDIT_V04_RU.pdf).
Её LaTeX-исходник и данные включены. Документы `COURSEWORK_RU.pdf`,
`MODEL_V2_RU.md` и результаты 0.2–0.3 сохранены для истории; их интерпретация
высыхания и ветвления заменена запиской версии 0.4.

## Основные экраны

Три кнопки всегда видны:

1. **Падение на коллектор — 2D**: полёт сбоку x–z и укладка сверху x–y,
   только с уже произошедшими попаданиями для выбранного времени.
2. **Высыхание по координате z**: испарившаяся доля исходного растворителя,
   с обозначением оставшейся доли. Условие полного высыхания не навязывается.
3. **Филаменты: устойчивость и сценарии**: физический скрининг деформации
   сечения. При отсутствии закона рождения **N(z) не определено**, а плоская
   линия N=1 не выдаётся за расчёт размножения. Экспертный популяционный
   сценарий отделён и не называется подтверждённым прогнозом.

«Открыть пример» загружает новый расчёт с геометрическим газовым переносом.
Старые расчёты открываются через «Открыть расчёт…» и сохраняют исходные
параметры. 3D, поле, диагностика и параметрическая сетка — в «Другие графики».
Экспорт: PNG/PDF/SVG, исходные числа CSV, геометрия VTP.

Кнопка **«Эксперимент и прогноз…»** открывает отдельное настольное окно:
таблица `z, значение, σ`, вставка из Excel и импорт CSV. Отдельные серии —
для среднего числа дочерних струй и для испарившейся/оставшейся доли
исходного растворителя. Подбор модели с насыщением или интерполяция PCHIP,
проверка с исключением целых координат вместе с повторами, условная полоса
неопределённости средней кривой, запрос значения при выбранной координате.
Экстраполяция по умолчанию выключена. Экспортируются график PNG/PDF,
прогноз и ошибки CSV, исходная серия, условия и параметры JSON.
Начальная таблица пустая; экспериментальные данные не придуманы.
Инструкция: [EXPERIMENT_RU.md](docs/EXPERIMENT_RU.md).

## Что исправлено в физике

Вместо постоянного k=0.01 м/с в новом примере решается цилиндрическая
газоплёночная задача: k=D/[a ln(R/a)], h=k_air/[a ln(R/a)]. R — явно заданная
неопределённая граница перемешанного газа. Добавлены стефановский поток пара,
активность Флори–Хаггинса и ограничение жидкой диффузией через параболическое
радиальное замыкание. Это не полное разрешение газовой фазы и оболочки полимера.

Альтернативный Churchill–Bernstein учитывает поперечное обтекание и сохраняет
флаг выхода за диапазон RePr/ReSc. Старое постоянное замыкание доступно
для сравнения и воспроизведения старых материалов. Температура связана с
теплотой испарения, конвекцией, джоулевым и вязкоупругим нагревом.

Нестационарная 3D-цепочка по-прежнему учитывает поле иглы, пары зарядов,
FENE-P, капиллярность, воздух и тяжесть. Шум теперь задан на общей физической
сетке, одинаковой при уточнении шага и интервала ввода. **Пространственная
сходимость амплитуды изгиба пока не достигнута.** Количественные траектории
и диаметры, зависящие от него, не объявлены аттестованными.

## Что означают новые результаты

Для базовых гипотез ПВС–вода, 10 кВ, 0.5 мл/ч, 100 мм и начального радиуса
3 мкм потеря воды к первому попаданию — около **8.0%**. Режим предсказывает
влажную нить. При изменении неопределённых параметров переноса — примерно
**1.2–10.8%**. Это диапазон выбранных гипотез, не доверительный интервал.

В независимой проверочной задаче с предписанной скоростью 5 м/с цилиндры
начального радиуса 3, 1 и 0.2 мкм теряют за 100 мм примерно 9.4%, 61.9% и
98.9% воды. Расходы при этих радиусах **различаются**. Это проверка переноса
без механической вытяжки, а не прогноз диаметра исходной струи.

Для настоящего числа дочерних струй нужны закон рождения/изменения топологии
и его валидация. Окно версии 0.5 позволяет оценивать **эмпирическую зависимость
по вашим измерениям**, но не превращает её в проверенный закон рождения.
Текущий скрининг сравнивает давление и проверяет условия
применимости предельной модели проводящего цилиндра; не превращает их в N.
Пользователь не предоставил марку ПВС и измерения: свойства и диапазоны
находятся в `configs/pva_uncertainty_ranges.json` и помечены как гипотезы.

## Растворы и насос

Меню: ПВС–вода 8/10/12 масс.%, ПЭО–вода 4%, ПВП–этанол 12%. Наборы
предварительные. «Новый материал…» сохраняет свойства и их источник;
материалы доступны после перезапуска и переносятся через JSON. Материалы
старого формата сохраняют старый закон переноса; новый формат — schema_version=2.

Вкладка «Насос» связывает диаметр шприца, ход винта, шаги двигателя и расход.
Вкладка «Испарение» содержит газовую границу, диффузию и активность. Обозначение
DRV8825 проверяется: максимум 1/32, а не указанные в README MIT 64 микрошаговых
импульса. Подробности: [HARDWARE_RU.md](docs/HARDWARE_RU.md).

## Запуск и проверки

Ubuntu: Python 3.12, GNU Fortran, Make и графический сеанс.
Обычно нужны `gfortran make python3-venv libegl1 libgl1 libxcb-cursor0`.

```bash
bash scripts/setup.sh
.venv/bin/python app.py
# Без дисплея: поле → интеграция → попадания → все графики
.venv/bin/python app.py --self-test
QT_QPA_PLATFORM=offscreen MPLCONFIGDIR=/tmp/elspin-mpl \
  .venv/bin/python -m unittest discover -s tests -v
```

Windows: распакуйте **весь** архив, оставьте `_runtime` рядом с `ElSpin.exe`.
Ни Python, ни сервер устанавливать не требуется. `CHECK.cmd` запускает
функциональную проверку. Windows-сборка кросс-компилирована в Linux;
на настоящей Windows в этой среде не проверена.

Проверки включают аналитическую газовую проводимость, насыщение, точный
закон адиабатического охлаждения, сравнение с независимым ОДУ, сохранение
полимера и заряда, проверку граничных режимов устойчивости и GUI.
Полные журналы: `results/tests-physics-v04.log`, `results/packaging-linux-v04.log`.
Проверки версии 0.5 также включают восстановление известных синтетических
кривых, исключение повторов при проверке, запрет необоснованной экстраполяции
и путь GUI «Excel → подбор → прогноз → экспорт → повторное открытие».
Верификация не означает экспериментальную валидацию ПВС.

## Повторение исследований

```bash
MPLCONFIGDIR=/tmp/elspin-mpl .venv/bin/python scripts/physics_audit.py --out results/new_audit
```

Скрипт рассчитывает диапазоны, контроли и уточнения, сохраняет неудачи с
причиной и отдельные конфигурации. Требуется новая папка; ранее сохранённые
результаты не перезаписываются. Для приложенного отчёта также сохранены
`results/physics_audit_v04`, `results/physics_material_audit_v04` и
`results/physics_report_v04`. Сборка Linux: `scripts/build_desktop.sh`;
Windows: `scripts/package_windows.py` или нативный `scripts/build_windows.ps1`.
